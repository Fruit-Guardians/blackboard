# blackboard Logo

Figma: https://www.figma.com/design/BqiNQ0iLRBJ7rbIC6Y2LRf?node-id=2-2

## 概念 · Open trace
开放边框代表可恢复的黑板；斜线代表探索轨迹；游离圆点代表 Agent 的当前位置。设计不以固定流程箭头或状态机来描述项目。

## 文件
- blackboard-logo-dark.svg：浅色背景使用，深色文字＋深绿图形。
- blackboard-logo-light.svg：深色背景使用，浅色文字＋薄荷绿图形。
- blackboard-logo-mono.svg：单色印刷、终端文档。
- blackboard-mark-mint.svg / blackboard-mark-dark.svg / blackboard-mark-white.svg：独立标志，透明背景。
- blackboard-app-icon.svg：512 × 512 应用图标，墨黑圆角底色。
- blackboard-identity.png：Figma 品牌板预览。

## 色彩与字体
Board #090D0C；Trace #66E0AE；Paper #F3F5F2。
浅底标志使用 #147453；深色文字使用 #15201C。
Figma 字标为 Manrope SemiBold，导出 SVG 已转轮廓，无字体依赖；说明使用 Inter / Noto Sans SC。

## 使用
独立标志最小 16 px；四周留白至少图标宽度的 1/4。
Figma 保留可编辑文字与矢量路径，右侧 EXPORT 区为生产素材。
项目运行代码与现有改动保持原样。
